02 · Kafka 개념

Kafka를 이루는 개념

PRODUCER

메시지 생산자

메시지(데이터)를 Topic에 발행하는 애플리케이션

TOPIC / PARTITION

메시지 분류자

Topic은 메시지 분류, Partition은 토픽 안에서 메시지를 저장하는 단위이며, 여러 파티션으로 나뉘어 병렬 처리가 가능

CONSUMER GROUP

같은 그룹의 소비자 모임

같은 그룹에서는 구독하는 토픽의 파티션마다 소비자 하나가 할당되고, 그룹별로 Offset 관리

Cluster

여러 Broker가 함께 구성하는 하나의 Kafka 시스템

Broker

Topic과 메시지를 저장하고, Producer와 Consumer의 요청을 처리하는 Kafka 서버

Replication

각 파티션의 복제본을 여러 Broker에 두는 기능.
하나는 Leader, 나머지는 Follower로 동작해 장애에 대비

Offset

파티션 안에서 각 메시지의 위치를 나타내는 번호

같은 Consumer Group 안에서 하나의 파티션은 한 시점에 한 소비자에게 할당. 그룹이 다르면 각 그룹이 독립적으로 읽을 수 있음.

offset 기록
자동 커밋에서는 처리 완료 시점과 offset 커밋 시점이 어긋날 수 있음
운영 요구사항에 따라 수동 커밋 또는 재처리 전략을 검토
자동 커밋은 설정된 주기에 따라 poll요청으로 받은 레코드의 읽기 위치를 커밋하나, 새 위치가 없으면 Offset은 갱신되지 않음
